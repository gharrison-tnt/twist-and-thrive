Memory Care Project

My own practice for memory care and assisted living communities. Built from two sides of the same problem.

My father has dementia. I've also spent 15 years building the systems that earn trust inside large organizations. Memory Care Project is where those two things meet.

It helps memory care communities close the gap between the care they deliver and the experience families and staff actually have. Clinical care can be excellent and families can still feel shut out. That gap is what this work is about.

I'm a Certified Dementia Practitioner. The work is built around five areas: communication, trust, education, engagement, and responsiveness.
